# L'Odyssée de l'IA
Ce dépôt a été réalisé dans le cadre d'un travail documentaire consacré à l'histoire et à l'évolution de l'intelligence artificielle.

L'objectif est de comprendre comment les avancées mathématiques et informatiques ont progressivement permis de passer de systèmes fondés sur des règles explicites aux modèles d'intelligence artificielle actuels.

## Problématique

Comment les idées mathématiques et informatiques ont-elles progressivement transformé la manière de construire l'intelligence artificielle, jusqu'aux systèmes actuels ?

## Contenu

Le travail revient notamment sur :

- les fondements de la logique et du calcul ;
- Alan Turing et les débuts de l'intelligence artificielle ;
- l'IA symbolique et le machine learning ;
- les réseaux de neurones et la rétropropagation ;
- le deep learning ;
- les Transformers et les modèles de fondation ;
- les systèmes multimodaux et les agents ;
- les limites actuelles de l'IA ;
- les perspectives autour de l'AGI, du quantum machine learning et de la conscience artificielle.

Une attention particulière est également portée aux mathématiques utilisées en intelligence artificielle, notamment l'algèbre linéaire, les probabilités, les statistiques et l'optimisation.
